# 🌟 Stardance

A cutting-edge web experience powered by **Three.js** and **Vite**, featuring immersive 3D graphics and modern web technologies.

## ✨ Features

- **3D Graphics**: Built with [Three.js](https://threejs.org/) for stunning visual effects
- **Fast Development**: Powered by [Vite](https://vitejs.dev/) for rapid development and optimized builds
- **Modern Stack**: ESM modules and contemporary JavaScript tooling
- **Responsive Design**: Mobile-friendly and optimized for all devices
- **Custom Styling**: Unique typography with Orbitron and Black Ops One fonts

## 🚀 Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/Alafandri/WebsiteProjectStardance.git
cd WebsiteProjectStardance
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

The application will be available at `http://localhost:5173` (or the next available port).

## 📦 Available Scripts

- **`npm run dev`** - Start the development server with hot module replacement
- **`npm run build`** - Build the project for production
- **`npm run preview`** - Preview the production build locally
