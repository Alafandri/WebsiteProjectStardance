# Stardance

A web experience powered by **Three.js** and **Vite**, featuring modern web technologies.

## Features

- **Fast Development**: Powered by [Vite](https://vitejs.dev/) for rapid development and optimized builds
- **Modern Stack**: ESM modules and contemporary JavaScript tooling
- **Responsive Design**: Mobile-friendly and optimized for all devices
- **Custom Styling**: Unique typography with Orbitron and Black Ops One fonts

## Browser Support

This project uses modern web standards. Works best in:
- Chrome/Chromium (latest)
- Firefox (latest)
- Safari (latest)
- Edge (latest)
